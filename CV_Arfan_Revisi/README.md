# Website CV Muhammad Arfan

Website CV pribadi responsif menggunakan HTML, CSS, Bootstrap 5, Bootstrap Icons, dan JavaScript.

## Menjalankan di laptop
1. Ekstrak ZIP.
2. Buka folder `website_cv_arfan_final` dengan Visual Studio Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.
4. Pastikan internet aktif karena Bootstrap, Bootstrap Icons, dan Google Fonts dimuat melalui CDN.

## Isi website
- Profil dengan foto Muhammad Arfan
- Tempat/tanggal lahir: Blora, 19 Mei 2006
- Pendidikan Universitas Budi Luhur
- Pendidikan SMK Bintang Nusantara, TKJ (2022–2025)
- Pengalaman PKL di AJ Computer sebagai teknisi
- Keahlian servis komputer dan laptop, jaringan, troubleshooting, HTML/CSS, Bootstrap, basis data
- Kontak

## Sebelum dipublikasikan
Ganti email contoh `arfan@example.com` dengan email aktif Anda. Tinjau deskripsi proyek dan kemampuan agar sesuai pengalaman yang benar-benar dimiliki.

## Publikasi GitHub Pages
1. Buat repository GitHub baru.
2. Unggah seluruh isi folder ini sehingga `index.html` ada di root repository.
3. Masuk ke Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu sampai URL GitHub Pages muncul.
